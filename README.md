# SScraper
## Program functions

this program is made to help finding car deals using SS.COM web barketplace

Using this program, you can save your filters for a car search and access them in one click
- You can update search results and check if there are any new car options
- Saves can be protected by password, so it can be securely used by multiple people in one PC

## User Guide
### Launching a program

If you are going to lauch it first time, you need to run an Install.bat file from a package. This will install necessary modules to run a program

NOTE: Python 3.7 or newer should be installed on a PC to run this program

### Creating a new task

1. Press ADD button on main winodws
2. Chose a name and password for your task
3. enter link to SS.COM with a car that you chose to search for
4. Press SEND button, and if you have an internet conncetion and the link is right, filters will appear
5. Enter your filters and press SAVE button, your task will appear in task list on a main windows

### Operations with task

By pressing on a task name from list, you can select it. If the task is secured with password, enter it below in password field BEFORE selecting a task.

Once task is selected, a list of links, if there are any, will appear on the right of a windows.

To update the list, press the UPDATE buton on the bottom of the link list

There are two folders in a list: NEW and ALL. New links, that were not found on a previous update, will appear in NEW folder. In ALL folder you will be able to see all of the links found after  an update.

To delete a task, select it and press DELETE button on the left of a menu.
